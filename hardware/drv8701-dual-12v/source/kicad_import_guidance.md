# 官方 KiCad 导入指引核对

来源：<https://prodocs.lceda.cn/cn/import-export/import-kicad/index.html>
读取日期：2026-10-09。本文只转录本次导入方案有关的官方要求。

- 「嘉立创EDA专业版支持导入 KiCad 5.1 和 KiCad 5.9 版本的格式文件。」
- 「在KiCad打开工程后，在顶部用压缩功能进行打包」，在专业版开始页导入 ZIP。
- 「KiCad 工程压缩请使用 KiCad 自带的打包功能，不要自行在文件夹打包，因为自带的打包功能会把原理图使用的库文件也自动打包。」
- 「PCB 导入后会自动重建铺铜，铺铜结果会有差异，请仔细检查。」

用户确认使用嘉立创 EDA 专业版网页端。网页端的「导入 KiCad」入口与「导入嘉立创 EDA 专业版」入口不同；本次采用前者。`.eprj3` 是另一种新版桌面文件夹工程，不能直接作为网页端 `.epro` 导入文件，也不能通过改名转换。

原始可编辑源工程来自 KiCad 9，不能仅将 ZIP 或文件版本标记改名来宣称支持旧版导入；本次另行产生真实 KiCad 5.1 格式的 `.pro/.sch/.lib/.kicad_pcb` 与本地封装库，并记录转换检查。

自动重建铺铜属于已定义铜区的填充，不是自动布线。本工程的元件布局与每段铜线均人工规划，未调用自动布线器。
