# 嘉立创 EDA 专业版网页端导入

采用用户提供的[官方 KiCad 导入指引](https://prodocs.lceda.cn/cn/import-export/import-kicad/index.html)。该页面列出 KiCad 5.1／5.9 支持范围，要求使用 KiCad 自带归档功能打包，并明确导入后会重新铺铜。

## 选择文件

请使用 **`DRV8701_12V_KiCad5_Import.zip`**。

- [从 GitHub 下载专用导入 ZIP](https://github.com/mczgoog-creator/codex/raw/refs/heads/main/downloads/DRV8701_12V_KiCad5_Import.zip)
- 完整资料包内也保留同一文件：`imports/DRV8701_12V_KiCad5_Import.zip`。

导入包内为真实 KiCad 5.1 格式的 `.pro`、`.sch`、`.lib`、`.kicad_pcb`，含本地符号、缓存库和封装库。原始 KiCad 9 文件仍保留用于审查；此前 `.eprj3` 是另一种新版桌面文件夹工程，不能作为网页端要求 `.epro` 的文件使用。

## 网页操作

1. 在嘉立创 EDA 专业版的**开始页**选择 **「导入 KiCad」**。如果文件选择器只允许 `.epro`，返回并切换到 KiCad 导入入口。
2. 直接选择 **`DRV8701_12V_KiCad5_Import.zip`**，让专业版导入原理图、PCB 与库。保持 ZIP 原文件，不改后缀，也不另行手工压缩。
3. 导入完成后打开原理图和 PCB，检查下面列出的尺寸、网络、铜区和规则，并运行专业版 DRC。
4. 保存导入后的工程。需要原生工程备份时，使用专业版自身的工程导出功能保存。

## 导入后核对

- 板框 **48×36 mm**，铜层 **4 层**，板厚 **1.6 mm**；四层铜的设计条件均为 **35 µm**。旧版文件不携带现代详细介质叠层，原叠层另存于 `KiCad_Import_5/stackup-source.kicad-sexpr.txt`；请在专业版确认制造叠层。
- **38 个元件、34 个网络**；控制接口 CN3 的原图四根信号顺序保持，无 GND 针脚，控制器需另行共地。
- 每路电机功率主线 **0.70 mm**，公共 VM 主干 **1.80 mm**。最小铜间距／普通最小线宽 **0.15 mm**，信号过孔 **0.45/0.20 mm**，电机输出转层孔 **0.80/0.40 mm**。导入器可能不迁移全部设计规则，需在专业版确认这些设置。
- GND 铜区共 **3 个**：F.Cu、In1.Cu、B.Cu。官方指引说明专业版会**自动重建铺铜**，因此要检查地平面连续性、功率焊盘接地、铜到线路的间距及未连接项。该重填是铜区填充，不是自动布线。

所有元件位置、原值、连接和原 258 条人工规划铜线均保留。导入副本补齐了原理图与 PCB 的元件标识关联，并增加 32 条完全位于 MOS 既有 Drain 焊盘铜内的 0.25 mm 短连接段，使 KiCad 5 能识别焊盘间已有的连接；因此副本总计 290 条线段、76 个过孔。独立几何包含证明确认这些短段新增实际铜面积为 **0.0 mm²**，不会扩大铜或改变外部布线。

新旧版本铺铜缓存的语义不同，旧版副本按原边界与参数重新填充，不能把缓存字节相同当作铜几何正确的证据。

## 验证与限制

原始 KiCad 9 源板的 DRC 为 0 违规、0 未连接；原理图 ERC 为 0 错误、0 警告。兼容副本也已用真实 **KiCad 5.1.9** 打开、重填和保存；实际 Eeschema ERC 为 **0 错误、0 警告**，实际 PCB DRC 为 **0 错误、0 未连接**。38 个元件及原值、34 个网络、173 个物理脚与独立源表一致。

旧格式转换、真实 KiCad 5.1 读取／保存／归档、网络与铜几何检查的证据见 `validation/kicad5-import-validation.json`、`validation/legacy5_final_pcb_equivalence.json` 及 `KiCad_Import_5/validation/`。

本云环境没有用户已登录的专业版网页会话，**尚未在真实网页端完成最终导入和 DRC**。这份包按官网支持格式制作，旧版软件检查不替代专业版实际导入检查，也不代表样板已通过通电和温升测试。原图电气差异和 MOS 焊盘／封装采购要求见 [README.md](README.md)。
